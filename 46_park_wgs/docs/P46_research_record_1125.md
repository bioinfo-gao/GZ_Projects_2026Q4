## 2. 研究步骤与实测结果

> 每个 stage 给出：做法 → 实测结果 → 产物路径。方法学上的返工与根因不在本文，见 1028 文档 §10.11。

### Stage 0 — 比对、去重、QC、样本身份核查（完成）

**做法**：`bwa-mem2 2.2.1 mem -t 36 -K 100000000 -Y` → `samtools sort`（2-way pipe）→
**GATK 3.4.0 MarkDuplicates 常规版**（非 Spark，Spark 版有 ELC 陷阱）→ `mosdepth 0.3.14 -n --by 1000` 默认模式。
不做 trimming（fastp 1.3.3 有数据驱动死锁；bwa-mem2 的 soft-clip 不伪造断点，属假阴性方向）。

**结果 1：深度必须双口径报告，否则会被误读成"没达到订单"**

| 口径 | 定义 | 实测范围 | 用途 |
| :--- | :---: | :---: | :---: |
| raw | read pairs × 2 × 150 bp ÷ 3.216 Gb | **46.4 – 63.0×** | **订单「45× raw」对应此项，已达标** |
| 有效覆盖 | mosdepth 默认（去 dup + mate-overlap 校正） | **20.7 – 32.8×** | 所有检出力论述以此为准 |

缺口原因已定量证明：本批 insert size 均值 **144.6–186.6 bp**，而读长 150 bp ⇒ 两条 mate 几乎完全重叠。
验证模型 `预测 = pairs × (1−dup) × min(insert, 302) / 基因组` 对 9 个样本的误差 ≤ 1.7%（均值 1.0%）
⇒ 缺口 100% 由"短 insert 的 mate 重叠 + 去重"解释，无第三个未知因素。
**重复率须一并报**：Sample_6 34.7%、Sample_2 15.2%、Ctr_2 12.1%，其余 4.3–7.2%。

**结果 2：10 个样本同源、无外源污染**
26,674 个常见 SNP 位点（gnomAD AF 0.3–0.7，每 100 kb 取 1 个），每样本可用 24,475–26,200 个。
两两基因型一致率 **0.9973–0.9981**（非对角线，共享位点 ≥ 24,000）⇒ 同一个体来源，无异源样本。
hom-alt 位点上的 REF 读段占比 **0.12%–0.26%**（与测序错误率同量级）⇒ 无可检出的人源交叉污染。
⚠ **设计局限（报告须写明）**：同亲本克隆之间的标签互换，此法无法检出。

**产物**：`/srv/.../46_park_wgs_bam/stage0_20261121/{bam,qc,coverage}`；
`analysis/stage0_identity_qc_20261123_v2/tables/`（identity_matrix / contamination / filter_impact）+ `multiqc/`

### Stage 1 — 靶点解剖（PPP1R2 Δ202，完成）

**做法**：逐切点判定（**不合并两切点求和** —— 合并会把"一条 Δ202 + 一条切点 indel"误判成"另一等位 WT"）。
三类证据并列：① 接头读段（soft-clip ≥ 20 bp 且 clip 序列与对侧下游参考一致度 ≥ 90%）；
② 干净跨越读段 / 带 indel 跨越读段（分切点计）；③ 缺失区归一化深度 `d_norm`。

**结果：缺失结构已定到碱基**
`chr3:195,542,948–195,543,149` 共 **202 bp**，左右断点 `195,542,947 / 195,543,150`，
接头处 **1 bp 微同源（C）** ⇒ 与 NHEJ 直接连接一致。

| 样本 | 先验 | 接头读段 | 判定 | 纯度 / 备注 |
| :--- | :---: | :---: | :---: | :---: |
| Ctr_1 / Ctr_2 / Ctr_3 | WT | 0 / 0 / 0 | WT（无 Δ202 证据） | 每切点干净跨越 12–25 条 ⇒ 阴性有覆盖支撑 |
| Sample_1 | 单等位 | 6 | 单等位 Δ202 | **亚克隆：Δ202 占比仅 29%**（两法互证 0.29 / 0.29–0.32） |
| Sample_2 | 单等位 | 4 | 单等位 Δ202 | **亚克隆：占比 32%**（0.32 / 0.24–0.33） |
| Sample_3 | 单等位 | 20 | 单等位 Δ202 | 与杂合一致（0.47 / 0.54–0.61） |
| Sample_4 | 单等位 | 8 | 单等位 Δ202 | 与杂合一致（0.60 / 0.50–0.67） |
| Sample_5 | 双等位 | 13 | **一条 Δ202 + 一条 CUT1 处 8 bp 缺失** | CUT1 干净跨越 **0**、带 indel 跨越 **12**；CUT2 干净跨越 13 |
| Sample_6 | 双等位 | 8,379 | **不可按表面值判读** | 见下方专条 |
| Sample_7 | 双等位 | 22 | 双等位 Δ202 | 两切点干净跨越均为 0 |

**Sample_1 / Sample_2 的克隆不纯**：两个**检出效率完全不同**的估计量给出同一个数（深度法 `1−d_norm`
与接头读段法 `J/(J+cross)`）⇒ 不是方法偏差。含义：这两个"单克隆"混有未编辑细胞；
Stage 4 的组间比较必须把等位比例写进去，否则会低估编辑组的差异。

**⚠ Sample_6 的靶点存在 amplicon 样污染**：靶点窗口读段数 **19,620**（其余样本 982–1,290，约 15–20 倍），
`d_norm = 3.26`（深度在"缺失区"反而**升高**），8,379 条接头读段中 13,085 条起始于 CUT2。
⇒ 该样本靶点基因型**不可按表面值判读**，与客户凝胶的双等位预期冲突，须单列证据表、不进等位比例统计；
该位点的深度类判据对它全部失效（倒位、串联重复等替代结局无法用深度排除）。
其余样本同窗口读段数 761–997，与对照同量级 ⇒ 无可检出的交叉污染。

**产物**：`analysis/stage1_ontarget_20261123/tables/`（ontarget_summary / junction / junction_reads /
indels_near_cutsites / supplementary_alignments / calibration_vs_client / filter_impact_audit）
⚠ `calibration_vs_client.tsv` 把 Sample_6 的"不可判读"计为 `agrees=yes`，故显示 10/10 一致；

### Stage 2 — 全基因组脱靶（客户主诉求，完成）

**2a 候选枚举**：3 条 spacer 版本（gRNA1 20 nt、gRNA2 19 nt、gRNA2 补全 20 nt）× 全基因组 ≤ 4 mismatch，
只用 spacer 搜、PAM 事后从参考实测；NGG 主表 + NAG 次表。继承 P31 的 **1,587 个候选位点**
（继承前已独立重新推导并通过定标断言：三条 spacer 的靶点必须被自己的流程以 0 mismatch + NGG 检出）。

**2b 逐位点证据（10 样本）**：每位点 × 每样本记录跨越深度、切点 ±10 bp 内的 indel 读段、
≥20 bp soft-clip 读段、MAPQ<20 占比，并**分开记录 primary / secondary / supplementary**
（secondary 是定位歧义的证据，supplementary 是 split/chimeric 结构的证据，不因"不是独立分子"而丢弃）。
样本级阳性判据（写死）：indel 或 clip 的 distinct read-name **≥ 3 且占该位点跨越深度 ≥ 10%**。

⚠ **接头排除只能按序列、不能按片段长度**（本批 insert ≈ 读长，按长度排会把真证据一起丢；
详见 1028 文档 §10.11⑬）。现行口径：仅当 clip 序列本身含 `AGATCGGAAG` / `CTTCCGATCT` 时排除。

**结果：无脱靶信号**

| 模式 | 位点数 |
| :--- | :---: |
| 无任何样本阳性 | **1,556** |
| 处理组与对照组都有（本底） | 20 |
| 仅处理组 | **7** |
| 仅对照组 | 1 |

**最小 Fisher p = 0.18**（7 vs 3 的理论最小值为 1/120 ≈ 0.0083）⇒ **没有任何位点在处理组显著富集**。
定标：靶点在 3 条 spacer × 10 样本共 30 格全部与预期一致（7 处理阳性 / 3 对照阴性）。

**2c 成对切点脱靶**（双切体系最危险的情形：两条 gRNA 在同一处都有近似位点且间距与靶点相近）：
全基因组仅 **6 处**间距 50–500 bp 的 gRNA1×gRNA2 配对，即靶点本身 + 5 个 PPP1R2 假基因家族位点
（PPP1R2B、PPP1R2P1、PPP1R2P4、PPP1R2P10、PPP1R2P2/RUNX1）。
**5 个假基因位点在 10 个样本中接头读段全为 0**，且每样本每切点干净跨越读段 ≥ 8（中位 14–26）
⇒ 这是**有覆盖支撑的阴性**，不是检不出。靶点本身在此步作为阳性对照通过（7 处理 > 0、3 对照 = 0）。

**报告必须写明的三条边界**：
1. 只支持 **mismatch**，不支持 DNA/RNA bulge（需 cas-offinder，本机未装）⇒ bulge 型脱靶属已知盲区；
2. 对照不是 CRISPR-naive ⇒ 结论层级为"与编辑共分离"；
3. 枚举只覆盖"序列近似"这一类脱靶，不覆盖脱靶后再经修复产生的远端事件（由 Stage 4 兜）。

### Stage 3 — 载体与递送物筛查（完成）

**做法**：每样本取候选读段（unmapped / mate-unmapped / clip ≥ 20 bp）回贴载体算覆盖度与拷贝数；
另取**基因组端 clip（≥25 bp, MAPQ≥20）回贴载体**求整合接头 —— 方向必须如此：载体是环状而参考是线性，
反方向（载体端 clip 回贴基因组）测到的是线性化假接口（P31 坑 #6/#7）。
覆盖度一律**排除人源同源屏蔽区** `pLPC_mCherry_BP1_2:5550-7260`（1,710 bp，载体内 53BP1 cDNA 段）
—— 这个 mask 是必需的：P31 第一版把 3 个"整合位点"全判在 TP53BP1，实为同源假象。
拷贝数分母用**未做 overlap 校正的去重深度**（载体侧 samtools depth 每个 mate 各计一次，分子分母须同口径）。

**定标（阳性 + 阴性双向通过）**

| 对照 | 预期 | 实测 |
| :--- | :---: | :---: |

| pLPC 骨架 AmpR | 逆转录病毒转导不应整合骨架 ⇒ 应为 0 | **10/10 样本全部 0.00** |

### Stage 4 — CRISPR 造成的其他变化
