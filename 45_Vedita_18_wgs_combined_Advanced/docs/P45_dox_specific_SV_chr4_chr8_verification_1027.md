## 1. 核查设计（证据模型）

| 研究问题 | 证据单位 | 保留规则 | 判定指标 | 允许的结论 |
| :--- | :---: | :---: | :---: | :---: |
| 携带者克隆里，区间的拷贝数是否改变 | 区间内的比对碱基（read depth） | MAPQ ≥ 20；不计 deletion；每个样本先除以自身侧翼中位数，再除以 S01–S03 的均值 | 杂合缺失约 0.5×；单拷贝获得约 1.5×；不变约 1.0× | 拷贝数是否改变、改变是否覆盖整个区间 |
| 区间内两条同源染色体是否都还在 | 在 S01–S03 中都杂合的 SNP（每个样本 DP ≥ 10，AF 0.3–0.7） | 携带者样本 DP ≥ 15 | 中位 \|AF−0.5\|：两拷贝约 0.07；1:2 约 0.167；缺失一条导致 LOH 时 > 0.4 | 是否存在 LOH 或 2:1 失衡 |
| 接头是否真实存在、来自几个分子 | 片段（read name） | 排除 duplicate 和 unmapped；接头片段要求 SA 指向另一个断点（±600 bp）；参考跨越片段要求 MAPQ ≥ 20 且断点两侧各 ≥ 20 bp | 接头片段数、起点是否各不相同、参考跨越片段数 | 接头序列是否存在于 DNA 中，而不是推断事件类型 |

**证据层级**：三层证据都来自同一批 BAM，但信号类型彼此独立（depth、SNP 等位比例、接头读段），不依赖 DELLY 的计数。它们**不是**独立 assay 层面的验证；独立验证需要 PCR 或 ddPCR（见 §4）。

**背景样本**：depth 层另外跑了 S06（GM12878）、S11（Mutu I）、S15（DG75），用来判断某个区间的 depth 是否在不同细胞系中都有系统偏差，即可比对性问题。

## 2. chr8 327 kb DUP（S04）：成立

### 2.1 三层证据

| 证据 | S04 | S01–S03 | S05 | 文件 |
| :--- | :---: | :---: | :---: | :---: |
| 区间 depth 比 S01–S03 均值 | **1.458** | 0.982–1.016 | 1.009 | `DUP00005675_depth_summary.tsv` |
| 区间内 12 个 25 kb bin 的比值范围 | 1.43–1.52 | — | — | `DUP00005675_depth_bins.tsv` |
| 区间外 74 个 bin 的比值均值 | 1.01 | — | — | 同上 |
| 杂合 SNP 中位 \|AF−0.5\|（区间内 / 侧翼） | **0.167** / 0.078 | 0.079 / 0.062–0.071 | 0.065 / 0.079 | `DUP00005675_allele_balance.tsv` |
| \|AF−0.5\| 落在 0.10–0.30 的 SNP 比例（区间内） | **0.711** | 0.283–0.329 | 0.327 | 同上 |
| DELLY 读段（discordant pair / junction read） | 3 / 5 | 0 / 0 | 0 / 0 | DELLY VCF 的 DV、RV 字段 |

### 2.2 怎么读

- **depth 台阶的边界与断点吻合**。bin 46,725,000 处为 1.06；从 46,750,000 开始升到 1.49，一直保持到 47,050,000 的 1.46；47,075,000 回到 1.00。两个断点 46,747,734 和 47,074,827 都落在台阶的边缘 bin 里。
- **1.46× 接近单拷贝获得在 clonal 群体中应有的 1.5×**。按 (2 + f)/2 = 1.458 估算，携带者细胞约占 92%，即 S04 克隆基本都携带这个获得。
- **等位比例给出了独立的同一结论**。3 个拷贝时，杂合位点的 AF 应为 1/3 或 2/3，\|AF−0.5\| = 0.167；实测中位数正好是 0.167，区间外为 0.078。depth 和 SNP 是两种互相独立的信号，结论一致。
- **DELLY 的 AF 只有 0.23，而且 somatic filter 没有通过，但这不说明事件不真**。DELLY 的 AF 只用断点附近的 discordant pair 和 junction read 计算，在本库插入片段很短的情况下（中位 TLEN 约 140–170 bp）会低估。这里的判定依据是 depth 和 SNP，不是 DELLY 的 AF。filter 未通过的具体原因没有查。
- **结构**：DELLY 给出的方向是 CT=5to3，这是串联重复（tandem duplication）的接头类型；与 depth 一起看，最直接的解释是一个 327 kb 的串联重复。插入到别处的可能性（非串联）没有排除，需要接头 PCR 才能区分。

### 2.3 位置与内容

- 位于 chr8 着丝粒（约 44.0–45.9 Mb）的长臂一侧，约 8q11.21。
- 区间内**没有 protein-coding 基因**（GENCODE v45）。有 LINC00293 和其他 lncRNA、若干 processed pseudogene，以及一组线粒体假基因（MTND1P7、MTND2P38、MTCYBP20 等）。
- 左断点 46,747,734 落在一个 segmental duplication 内：chr8:46,713,285–46,752,126，与 chr8:46.55 Mb 一带的同一性为 92.3%。断点 reads 的 SR MAPQ 为 60，但精确碱基位置仍要以 PCR 测序为准。

## 3. chr4 "888 kb DEL"（S05）：不是 deletion

### 3.1 区间本身没有丢失

| 证据 | S05 | S01–S03 | S04 | 文件 |
| :--- | :---: | :---: | :---: | :---: |
| 区间 depth 比 S01–S03 均值（17 个 50 kb bin） | **1.041** | 0.994–1.013 | 1.007 | `DEL00003167_depth_summary.tsv` |
| 区间内 S05 逐 bin 比值 | 1.01–1.07 | — | — | `DEL00003167_depth_bins.tsv` |
| 杂合 SNP 数（DP ≥ 15） | 358 | 214–281 | 282 | `DEL00003167_allele_balance.tsv` |
| 中位 \|AF−0.5\|（区间内 / 侧翼） | 0.079 / 0.079 | 0.062–0.079 | 0.088 / 0.079 | 同上 |
| \|AF−0.5\| > 0.4（类似 LOH）的比例 | **0.000** | 0.000 | 0.000 | 同上 |

- 如果 S05 克隆在一条同源染色体上丢了这 888 kb，depth 应降到约 0.5×，358 个杂合 SNP 应全部变成 LOH。实测 depth 1.04×，LOH 比例为 0。
- depth 的精度足以排除"小亚克隆携带缺失"：17 个 bin 的比值都在 1.01–1.07，携带缺失的细胞比例若超过约 10%，就会看到 ≤ 0.95 的下降。
- **DELLY 自己的 depth 字段也不支持缺失**：S05 的 RDRATIO = 1.007，RDCN = 2。该字段没有被用于事件分级。

### 3.2 但接头是真的

| 样本 | 断点 A（156,284,229）接头片段 | 其中含接头序列（adapter） | A 处参考跨越片段 | 断点 B（157,172,208）接头片段 | B 处参考跨越片段 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| S01 | 0 | 0 | 10 | 0 | 5 |
| S02 | 0 | 0 | 8 | 0 | 14 |
| S03 | 0 | 0 | 7 | 0 | 11 |
| S04 | 0 | 0 | 5 | 0 | 10 |
| S05 | **8** | 4 | 3 | **8** | 12 |

文件：`DEL00003167_junction_reads.tsv`；S05 的逐条记录见 `DEL00003167_S05_split_records.tsv`。

- S05 的 8 个接头片段在断点 A 侧的起点各不相同（156,284,119 到 156,284,196），read name 来自不同 tile，所以是 **8 个独立分子**，不是同一分子的 PCR 重复。随机嵌合 artefact 不会在 8 个独立分子上重复出现同一对碱基级断点，所以这个接头序列确实存在于 S05 的 DNA 里。
- 有 4 个片段含 adapter 序列，原因是插入片段很短（64–118 bp），读穿到了接头。这与 P45 其他接头的情况相同，不说明是 artefact。
- 为什么没有一对 discordant pair（PE = 0）：本库插入片段中位数约 140 bp，比 read length 还短，所以几乎所有接头证据都以 split read 的形式出现。PE = 0 本身不能用来否定事件，判定还是要靠 §3.1 的拷贝数证据。
- **S01–S04 一个接头片段都没有**，所以这是 S05 特有的。

### 3.3 那它是什么：接头远端约 3.4 kb 的小片段拷贝数增加

S05 中断点 B 附近的 250 bp 分辨率 depth（文件 `DEL00003167_fine_depth_breakendB_250bp.tsv`，S05 比 S01–S03）：

| 相对 157,172,208 的位置 | S05 比值均值 |
| :--- | :---: |
| −2,000 到 0 bp | 0.97 |
| **0 到 +3,500 bp** | **1.56** |
| +3,500 到 +8,000 bp | 0.95 |

- 拷贝数增加**正好从接头位置 157,172,208 开始**，持续约 3.4 kb，到约 157,175,500 结束，幅度约 1.5×，与单拷贝获得一致。
- 增加的区段延伸进一个 L1PA3 元件（157,174,892–157,180,916）。断点 A 右侧约 300 bp 处也有一个 L1PA2 元件（156,284,540–156,290,599）。两者都是年轻的 L1，彼此高度相似。
- **最符合全部数据的模型（推断，未实证）**：S05 中，chr4:157,172,208 至约 157,175,500 这一约 3.4 kb 的片段多了一份拷贝，插入到 156,284,229 附近，插入片段的远端在 L1PA3 内，回接到 156,284,540 起的 L1PA2。L1 对 L1 的这个接头在短读长数据中无法唯一比对，因此看不到。读出的效果是：一个看上去像"888 kb deletion"的接头，加上一个 3.4 kb 的小片段获得，中间 888 kb 原样保留。
- **已排除的其他读法**：
  - 克隆性杂合缺失：被 depth 和 LOH 排除（§3.1）。
  - 亚克隆缺失：被 depth 精度排除；而且 8 个接头片段对 3–12 个参考跨越片段，接头的比例远高于小亚克隆所能给出的水平。
  - 随机文库嵌合：被"8 个独立分子、碱基级断点一致"排除。
  - copy-neutral 平衡重排（888 kb 片段整段搬到别处）：断点附近没有发现指向其他位置的 SA 聚簇。但如果另一端也在重复序列里，这一点无法完全排除。
- **未解决的部分**：插入的远端接头没有被直接观察到。增加区段末端 157,175,359 处有一簇 right soft-clip reads，但已核查不是接头：S01–S05 各有 1–9 条，被剪掉的部分都是 adapter 序列（`GATCGGAAGAGC…`），而且 MAPQ 为 0，属于短插入片段读穿到 L1 内部，所有样本都有。另外，断点 A 附近的 1 kb bin 在所有样本里 depth 都偏低（S01 为 0.52），说明该处可比对性差，S05 的 0.42 不能单独解读成小缺失。
- **基因背景**：157,172,208 位于 GLRB 基因末端（157,172,090）下游 118 bp，增加的 3.4 kb 不含 GLRB 的外显子。156,284,229 一侧 ±15 kb 内没有基因。
