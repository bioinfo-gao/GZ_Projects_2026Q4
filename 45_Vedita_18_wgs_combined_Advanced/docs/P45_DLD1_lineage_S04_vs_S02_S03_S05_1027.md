# P45 DLD1 克隆的亚谱系：S04 与 S02、S03、S05 来自不同亚谱系（18 个不一致位点的成因）

- 日期：2026-10-27
- 状态：内部文档，待审阅。不改动任何报告。
- 起因：`docs/P45_same_chr11q_homolog_explanation_1027.md` §2.4 中，远端 11q 有 18 个位点两克隆保留的等位基因不同，而且全部是 S04 保留 ref、S05 保留 alt，反向组合为 0。

## 0. 结论

1. **18 个位点的成因已查明。** 它们是 S02、S03、S05 所属亚谱系特有的体细胞 SNV，位于两个克隆保留的那条 homolog 上；S04 不属于这个亚谱系，从来没有这些 SNV。这不是丢了不同的 homolog，**"同一条 homolog"的结论不变**。
2. **为什么只有一种组合**：BAF 分析只用"在 S01–S03 中都杂合"的位点。S02、S03、S05 共有的 SNV 能通过这个筛选；S04 独有的 SNV 在 S02、S03 中不存在，永远通不过。所以反向组合是 0，是筛选造成的，不是生物学上的不对称。
3. **更重要的发现**：S04 和另外三个 DLD1 克隆（S02、S03、S05）来自 DLD1 群体中**不同的亚谱系**。这影响报告里"S04 特有事件"的解读（见 §4），需要你决定怎么处理。

## 1. 18 个位点的直接证据

文件：`analysis/20261027_dld1_lineage/distal11q_discordant_sites.tsv`（18 行，含 S01–S10 全部 allele depth）。

| 样本 | 18 个位点上的表现 |
| :--- | :---: |
| S01（群体） | 杂合，但 alt 比例偏低，约 0.25（如 4/15、3/12、5/20） |
| S02、S03（无 Dox 对照克隆） | 杂合，alt 比例约 0.5 |
| S04 | 只有 ref（DP 8–12） |
| S05 | 只有 alt（DP 8–13；128,127,764 处为 10 alt / 1 ref） |
| S06–S10（GM12878） | 全部没有 alt |

- 两克隆的 depth 都正常（8–13），MQ 54–60，QUAL 669–907：不是低深度或比对质量造成的。
- 群体 S01 的 alt 比例只有约一半，说明这些 alt 只存在于群体中一部分细胞里，是亚克隆性的体细胞突变，不是胚系杂合。

## 2. 全基因组验证：克隆之间共有 SNV 的模式

数据：联合调用 VCF（QUAL ≥ 30）的全部常染色体双等位 SNV；要求 S01–S05 每个样本 DP ≥ 8、GM12878 五个样本都没有 alt reads（排除胚系变异）；携带 = AF 0.25–0.75，不携带 = 0 个 alt read。文件：`analysis/20261027_dld1_lineage/clone_snv_sharing_autosomes.tsv` 与逐染色体的 `clone_snv_sharing_by_chrom.tsv`。

| 携带模式 | SNV 数（常染色体） | S01 中的 AF（各染色体中位数的中位数） | 解读 |
| :--- | :---: | :---: | :---: |
| 只在 S04 | 121,783 | 0.049 | S04 所属亚谱系的 SNV（群体中约 10% 的细胞）加上 S04 克隆自身的突变 |
| S02 + S03 + S05 共有 | 84,480 | 0.10 | 三者共同亚谱系的 SNV（群体中约 20% 的细胞） |
| 只在 S05 | 19,111 | 0.0 | S05 单细胞克隆化之后的自身突变 |
| 只在 S02 | 15,515 | 0.0 | 同上 |
| 只在 S03 | 14,249 | 0.0 | 同上 |
| S02 + S03 共有 | 8,589 | 0.0 | S02、S03 之间更近 |
| 任何包含 S04 的共有模式（4 种） | 18–617 | — | 极少 |

- 推出的关系：S04 自成一支；S02、S03、S05 共享一段很长的共同历史（84,480 个 SNV），其中 S02、S03 彼此更近。
- S04 和其他任何克隆的共有 SNV 都只有几百个，说明 S04 所在亚谱系在 DLD1 群体中很早就分开了。
- "群体中约 X% 的细胞"按杂合 SNV 的 AF × 2 估算，是推断，精度有限。

## 3. 对已有结论的影响

| 结论 | 影响 |
| :--- | :---: |
| 两个克隆丢的是同一条 chr11q homolog | 不变。18 个位点的 alt 是 S05 亚谱系的标记，正好落在保留的那条 homolog 上 |
| 两次 chr11q 丢失是独立事件 | **加强**。原依据是断端不同；现在还知道 S04、S05 来自不同亚谱系，两次丢失发生在不同的细胞谱系里 |
| 两个克隆打在同一条 homolog 上的偶然概率为 1/2 | 不变 |

## 4. 需要你决定：对"+Dox-specific"解读的影响

报告的克隆比较以 S01–S03 为基线：事件在 S04 或 S05 中存在、在 S01–S03 中都不存在，就叫 +Dox-specific。

- **对 S05**：基线里有同一亚谱系的 S02、S03。S05 特有事件更可能是 S05 克隆化之后（包括 Dox 处理期间）才出现的。
- **对 S04**：基线里**没有** S04 所属亚谱系的克隆，只有群体 S01，而该亚谱系在 S01 中约占 10% 的细胞。一个在 S04 亚谱系中早已存在的结构变异，在 S01 中的 AF 约 0.05；以 S01 约 16× 的深度，大多只能看到 0–1 条支持 read，会被判为"S01–S03 中不存在"。所以 **S04 的"+Dox-specific"事件中，有一部分可能是亚谱系原有的，而不是 Dox 处理后产生的**。
  - 受影响的是 §7.9 中 S04 的 8 个全基因组事件（包括 chr8 327 kb 获得）。
  - chr11 位点的事件受影响较小：两个来自不同亚谱系的 +Dox 克隆都在同一处断裂、丢失同一段，这本身就很难用亚谱系原有变异来解释。但 S04 的 J0922 本身是否在 S04 亚谱系中早已存在，单靠现有数据不能排除，只能说 S01 中没有看到支持 read（报告：S01–S03 分别有 13、12、24 个 reference fragment）。

可选的处理方式（建议，未执行）：

| 方式 | 内容 | 工作量 |
| :--- | :---: | :---: |
| A. 只在报告中说明 | Methods/Limitations 加一段：S04 与 S02、S03、S05 来自不同亚谱系，基线中缺少 S04 亚谱系的克隆，S04 特有事件不能排除早于 Dox 处理 | 小，只改文字 |
| B. 量化 S01 中的检出力 | 对 S04 的每个特有事件，按 S01 深度和"亚谱系约 10% 细胞"计算 S01 中预期的支持 read 数，标出哪些事件在 S01 中本应可见 | 中，约 1 小时 |
| C. 加入 Next Steps | 建议客户提供 S04 亚谱系的无 Dox 克隆，或对 S04 亚谱系做靶向检测 | 小，只改文字 |

我倾向于 A + C；B 能把"不能排除"具体到每个事件，你觉得需要再做。
