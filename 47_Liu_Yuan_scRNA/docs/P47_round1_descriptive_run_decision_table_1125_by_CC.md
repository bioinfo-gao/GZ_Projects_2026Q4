## 0. 本轮做什么、不做什么（一句话）

**做：** 不依赖客户设计信息即可成立的**描述性**分析 —— 工程预检、Flex 特异体检、逐样本 QC、doublet、深度不均衡量化、整合聚类、ambient 背景、pseudobulk 资产导出、描述性效应量、方法学自证。

**不做（本轮硬边界）：** 任何**跨条件 p 值 / FDR**、任何 edited-vs-control 的**归因**结论、任何**细胞类型注释**、任何通路**结论性**解读、任何**碱基编辑**判定。

## 1. 为什么本轮不给 p 值 —— 三条独立理由，各自都足够

| # | 理由 | 实测依据 | 性质 |
| :--- | :---: | :---: | :---: |
| 1 | **设计门槛不足**：`/scrna` §1.1 规定每组 n≥3 独立样本才能做跨条件推断；本项目最乐观读法下每条件 n≤2，最可能是 **8 条件各 n=1** | 客户 4+2+2 与 8 个标签的计数吻合（推断，待确认） | 统计学 |
| 2 | **主方向完全共线**：edited 4 样全在 pool 1、control 4 样全在 pool 2，无跨 pool 桥接样本 | `config.csv` × 2、probe barcode 实测 A-A10…A-D10 / A-E10…A-H10 | 设计 |
| 3 | **独立性被结构性破坏**：Flex 同 pool 内 GEM 重叠 11.4%–17.4%，同 pool 样本并非完全独立观测 | `frp_gem_barcode_overlap.csv` × 2 | 测量 |

**⇒ 本轮输出"方向与效应量"，不输出"显著性"。** 阴性写法按规则：非显著但效应不为零 ⇒ 写 "no statistically significant …"，**不写"无变化"**。本轮更进一步 —— **连"非显著"都不写**，因为没做检验。

## 2. 研究问题 → 证据单位 → 过滤规则 → 判定指标 → 允许的结论

| # | 研究问题 / data universe | 观察/证据单位 | 保留、去重与过滤规则 | 判定指标与 filter-impact audit | 本轮允许的结论 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| A | 工程前提是否成立（env / 包 / 已知静默坑） | 脚本符号 × 已安装包 | 0 算力静态扫描；逐"会被调用的函数"验证，不止 `library()` | 缺包/缺加载清单；scDblFinder×xgboost 直接调 `.xgbtrain` | 通过/不通过，**不通过即 `stop()` 不往下跑** |
| B | 这批矩阵的真实结构是什么（Flex 特异） | 8 份 `sample_filtered/raw_feature_bc_matrix.h5` | 按 `gene_ids` 合并不按 symbol；`var_names_make_unique()`；显式加样本前缀 | MT 基因实测数（**面板只有 12，非人类常规 13**）、barcode 长度 26 nt、`feature_types` 单一、raw/filtered 比 | 可陈述结构事实；**任何与常规 3′ 假设冲突处以实测为准** |
| C | 每样本的技术质量如何 | sample × cell | **逐样本 MAD 自适应阈值**（不用固定阈值）；逐样本跑 doublet（不合并后跑） | 每样本过滤前后 barcode 数 + 原因；输出 machine-readable excluded table | 可报告逐样本 QC；**不把低复杂度读成生物学** |
| D | 深度不均衡有多大、会不会伪装成生物学 | sample 级 read/UMI 预算 | 不做任何"看起来合理"的归一化替代；深度校正前后各出一版 | `Reads in cells` 极差（实测 2.98×）；下采样到同深度后复查 | 可定量陈述不均衡；**凡深度相关指标必须同时给校正前后两版** |
| E | 293T 内部有无状态异质性 | sample × cell；**非独立实验重复** | pool 作批次做整合；HVG **只打标记不子集化**；counts 存 `layers['counts']` | 整合前后批次/生物指标并排；**不该变的有没有变** | 可做探索性状态描述；**293T 是单一细胞系 ⇒ 不做细胞类型注释**，主轴预期为细胞周期 |
| F | ambient 背景污染程度 | 簇 × 基因（**ρ 估计必须在聚类之后**） | 判"该簇不表达 g"用**簇均值 ≤ 5% × 最高簇**，再拿该簇全部细胞测量；**禁止用被测基因自己的分位数圈背景** | ρ 估计值 + 背景细胞数 + `assert bg_counts > 0` | 可报告 ρ；**pool 内多样本情形，不当单样本 soup 处理** |
| G | 可复分析资产 | sample × gene 的 **raw-count** pseudobulk | 聚合 raw counts（求和，整数）；剔除 <10 细胞的格子并列出 | 每格细胞数；剔除清单 | 导出 counts + coldata CSV，供后续（设计明确后）建模 |
| H | 各对比的方向与幅度 | sample-level pseudobulk logFC | 仅在 pool 内构造对比；不合并不同 control 类型 | **只给 logFC 与排序，不给 p/FDR**；标注 n | **描述性方向**，不得写成"差异显著"或"无变化" |
| I | 伪重复到底有多危险（方法学自证） | 对照组内部**随机对半** | 在同一数据上跑细胞级检验 | 报告"照样检出 N 个显著基因" | 作为报告附录证据，支撑第 1 节的"不给 p 值" |

## 3. 每条过滤规则为什么服务于研究问题（删掉它会漏掉什么）

| 过滤 | 服务于 | 删掉它会怎样 |
| :--- | :---: | :---: |
| 逐样本 MAD 而非全局固定阈值 | C | 全局一刀切会整体判掉某个样本；且系统性丢低 RNA 含量细胞 |
| 剔除 <10 细胞的 pseudobulk 格 | G、H | 会得到 2 个细胞支撑的"效应量" |
| 不用 UMI 阈值切 raw 代替 filtered | B、C | cell calling 是统计检验不是阈值；强行切错判 ≈6.8% 且偏向低 RNA 细胞 |
| 保留 raw 矩阵 | F | raw 是 ambient 校正**唯一**原料，扔掉就做不了 F |
| ρ 的背景细胞判据独立于被测基因 | F | 循环论证，结果按构造恒为 0（proj22 实测 6 个示踪基因 5 个返回 0.000） |
| HVG 只打标记 | E | 子集化不可逆，经典 marker 常不是 HVG |

**filter-impact audit 要求：** 每步输出过滤前后 **cell / barcode / gene** 三个计数与原因，并保留 machine-readable excluded table。**没有输出"被过滤的是什么、过滤了多少"，不得声称某类证据不存在。**

## 4. 本轮预设的阳性/阴性对照断言（失败即停）

| 断言 | 期望 | 抓什么 |
| :--- | :---: | :---: |
| `MT-` 基因实测数 | **12**（面板事实，非 13） | 前缀写错 ⇒ `pct_counts_mt` 全 0，零报错被读成"质量很好" |
| barcode 长度 | 26 nt（16 GEM + 10 probe BC） | 用 `bc.split("-")[0][:16]` 会静默截错 |
| 8 样本 cell 数 | 与公司 QC 逐一吻合（15,245 / 19,027 / 20,706 / 15,726 / 20,780 / 20,053 / 12,480 / 12,027） | 读入/拼接错样本 |
| `feature_types` 唯一值 | 只有 `Gene Expression` | 混进其它模态 ⇒ HVG 选出垃圾，图照画但无意义 |
| ambient 背景细胞 count | `> 0` | 背景选法退化 ⇒ 返回长得像结论的 0 |
| 带随机性步骤 | 同参数跑两遍产物 `cmp` 一致 | 未初始化内存 / `seed=0` 被当未给（实测坑） |
| 细胞周期 | 293T 应检出明显 cycling 结构 | 若完全无结构 ⇒ 先怀疑读入/归一化出错，而非"生物学上没有" |

## 5. 什么情况下必须停下来问（本轮不自行决定的事）

- 若需改变 **data universe**（例如决定排除某个样本）、**证据单位**、**去重口径**、**候选定义**或**结论层级** ⇒ 停，向用户说明后再跑。
- 若实测发现与本表任何前提冲突（例如 cell 数对不上公司 QC、MT 基因数不是 12）⇒ **停止把现有产物表述为完整答案**，保留代码/参数/日志/产物与问题审计，不删除、不原地覆盖，重新设计后以**新目录/新日期**运行。
- 本轮**不**进入客户交付环节（交付需设计信息）；所有产物为内部审阅，**不对外发送**。

## 6. 资源与工程约定

| 项 | 本轮设定 | 理由 |
| :--- | :---: | :---: |
| 线程上限 | **16**（不是 28） | 我方 P46 DELLY 4 路发现相正在跑（ETA ~22:00），全机 28 核/56 线程硬顶须共享 |
| 输入盘 | 先一次**顺序**暂存 2.9 GB 到 SSD | `/srv/external_data` 是机械盘且 P46 正在同盘做 70 GiB 拷贝；并发读是负优化 |
| 长任务 | 全部进 **tmux** | 远程服务器，Bash 后台模式绑会话 |
| 产物落盘 | 只写**新目录/当日新文件**，绝不原地覆盖 | 让"中途打断"永远安全 |
| checkpoint | 每步只读上游、只写自己那个 | 出事时可 `--from <步>` 续跑，不从头再来 |
